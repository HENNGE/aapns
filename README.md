# AAPNS

[![workflow](https://github.com/HENNGE/aapns/actions/workflows/workflow.yml/badge.svg)](https://github.com/HENNGE/aapns/actions/workflows/workflow.yml)
[![crates.io](https://img.shields.io/crates/v/aapns.svg)](https://crates.io/crates/aapns)
[![docs.rs](https://docs.rs/aapns/badge.svg)](https://docs.rs/aapns)

Asynchronous Apple Push Notification Service client.

* Requires TLS 1.2 or better
* Requires a [Tokio](https://tokio.rs) runtime
* Rust 1.85 or better

## Installation

```sh
cargo add aapns
```

## Quickstart

```rust
use aapns::api::{Client, SendOptions, Server, Target};
use aapns::config::Priority;
use aapns::models::{Alert, Localized, Notification};

async fn send_hello_world() -> aapns::errors::Result<()> {
    let client = Server::production("/path/to/push/cert.pem").create_client().await?;
    let notification = Notification {
        badge: Some(42),
        ..Notification::new(Alert::new(Localized::with_args("Hello World!", ["foo", "bar"])))
    };
    let options = SendOptions { priority: Priority::Immediately, ..SendOptions::default() };
    let apns_id = client.send_notification("my-device-token", &notification, &options).await?;
    println!("Sent push notification with ID {apns_id:?}");
    client.close().await;
    Ok(())
}
```

Clients are meant to be long-lived: create one when your app starts and close
it at the end of the app's life cycle. A client for a `Server` keeps a pool of
connections, reconnecting and retrying as needed.

To send to an iOS simulator instead, use `Simulator::new(device_id, app_id)`
as the target.

See the [documentation](https://docs.rs/aapns) for the mid level (connection
pool) and low level (single HTTP/2 connection) APIs, and for notes on
idempotency.

## Command line client

For testing, aapns includes a small command line client:

```sh
cargo install aapns --features cli
aapns server --client-cert-path /path/to/push/cert.pem <device token> "Hello World!"
aapns simulator booted com.example.app "Hello World!"
aapns --help
```

## Development

```sh
cargo test --all-features
cargo clippy --all-targets --all-features -- -D warnings
cargo fmt --all
```

The functional tests run against an in-process mock APNs server
(`tests/common/server.rs`). To try the command line client or the examples
against it:

```sh
cargo run --features cli --example mock_server -- --port 2197 &
cargo run --features cli -- server 42 "Hello" --server local --alt-port \
    --client-cert-path tests/certs/client.pem
cargo run --release --features cli --example pool_benchmark -- 2000
```

The test certificates in `tests/certs` are generated by
`tests/certs/generate.sh`.
